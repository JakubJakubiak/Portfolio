## Featured case — 71× overview paint

Production live operations panel for energy storage and industrial sites. [jakubjakubiak.com/#ems](https://jakubjakubiak.com/#ems)

| What the operator sees | Before | After |
|---|---|---|
| Overview rings — time to paint | ~19 s | **~0.26 s (~71×)** |
| Empty line charts (skeleton) | 35 s | **~0.6 s** |
| Vendor cloud write | — | **0 GB** |

Time-series store on a **second machine**, not on the API. Separate win from the 71× paint. No client names, plant IDs, or wiring in public notes.

Stack: Node.js · React · MQTT · TypeScript · Docker
